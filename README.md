# 🎰 Python Console Slot Machine Game

## Overview

A simple console-based slot machine game built using Python. Players can deposit money, select the number of lines to bet on, place bets, and spin a 3×3 grid of symbols. Winnings are calculated based on matching rows, and the balance updates after each round.

## Features

* Deposit and manage balance
* Choose number of betting lines (1–3)
* Adjustable bet per line
* Random 3×3 slot grid generation
* Win calculation based on symbol matches
* Continuous gameplay until user quits

## How to Run

```bash
python slot_machine.py
```

## How to Play

1. Deposit an amount to start
2. Select number of lines (1–3)
3. Enter bet amount per line
4. Spin the slot machine
5. Win if symbols match in a row
6. Balance updates automatically
7. Continue playing or quit anytime

## Requirements

Python 3.x
